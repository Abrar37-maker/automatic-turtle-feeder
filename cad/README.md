# CAD & Mechanical Design Files

This directory contains the 3D Computer-Aided Design (CAD) files for the **Automatic Turtle Feeder**.

---

## 📁 Files Included
- **`Autonomous Pet Turtle Feeder.f3d`**:
  - Full parametric CAD assembly in Autodesk Fusion 360 archive format (`.f3d`).
  - Contains complete 3D mechanical models including:
    - Pellet hopper and dispensing funnel
    - Servo-actuated gate mechanism
    - Agitation motor mount and internal impeller
    - Sensor brackets (HC-SR04 sonar overhead mount, IR bowl alignment sensor slot)
    - Electronics mounting enclosure for ESP32 and L298N driver

---

## 🛠️ How to Open and Export
1. Download or clone this repository.
2. Open **Autodesk Fusion 360**.
3. Go to **File** &rarr; **Open...** &rarr; **Open from my computer** and select `Autonomous Pet Turtle Feeder.f3d`.
4. To 3D print any individual body/component, right-click the body in Fusion 360 and choose **Save as Mesh / Export as STL / 3MF**.
